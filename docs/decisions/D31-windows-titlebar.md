# D31. Windows 桌面顶栏透明，各列延伸到窗口顶端

- **状态**：已实施
- **分组**：宿主边界
- **关联**：D3

## 决定

- Windows 桌面端（`html[data-windows-titlebar]`）的顶栏没有自己的颜色。宿主在各列上方留出的一行（框架的 `padding-top`，由框架本身与它的 `::before` 拖动条刷成侧栏底色）改为透明，侧栏与对话列各用一层向上偏移顶栏高度的外阴影（`box-shadow`）把自己的底色延伸进这一行。
- 侧栏右边的分隔线由侧栏的拖动把手（`[data-side="sidebar"]`）的 `::before` 向上画过这一行；宿主的 `--dsh-windows-content-radius` 设为 0，对话列与全屏文件面板左上角不再有圆角。
- 窗口按钮下的底色由系统绘制，颜色来自宿主桌面端 preload 放在 `<body>` 下的隐藏探针 `<span>`（读 `--dsw-specific-sidebar-fill`，交给 `setTitleBarOverlay`）；皮肤把这个探针的 `background-color` 设为透明，按钮下露出页面本身，弹窗遮罩盖上来时按钮区随页面一起变暗。实测透明后按钮的悬停高亮照常，系统按图标颜色叠一层约一成浓度的颜色。

## 理由

- Claude Code 桌面端的侧栏与主界面都通到窗口顶端，一条分隔线从上到下。外阴影只画在列的盒子外面，列里的内容和宿主的布局都不动，拖动列宽与收起动画时自动跟着列走。

## 代价

- 认探针靠它内联样式里的 `--dsw-specific-sidebar-fill` 子串，属于宿主 preload 的内部写法、不是公开契约（D3 的例外，记在这里）；宿主改了写法，按钮区退回宿主的底色，不会出错。
- 收起侧栏时宿主立即移除拖动把手，顶栏里那段分隔线比列宽动画先消失。

## 重审条件

- 宿主的桌面端提供顶栏透明的选项或按钮区底色的公开接口时改用宿主的。
