# D4. 输入框样式的构建期门控

- **状态**：已实施
- **关联**：D51

## 决定

- 输入框相关的样式规则写在 `/* @composer-gate */` 标记之下；构建在语法树上把门控属性（`COMPOSER_ATTR`）盖到标记以下每一条规则的作用域那一段上（D51），缺少标记或标记以下没有规则即构建失败。
- 门控属性由输入框功能按「输入框重绘」偏好与当前页面写在 `<body>` 上；偏好关闭或功能退役时，这些规则整体失效。

## 理由

- 输入框是性能与正确性最敏感的区域，它的规则必须能随一个开关整体撤下。

## 代价

- 写输入框样式要放在标记之下；构建维护门控逻辑。

## 重审条件

- 无，这是安全网。
