# D52. 右侧面板：宿主的 dockkit 结构，皮肤的暖色表面

- **状态**：已实施
- **关联**：D3、D9、D19、D30

## 决定

- 右侧面板沿用宿主的右栏与 dockkit 页签宿主：`[data-rightbar-col]` 内是 `[data-dockkit-pane]`，页签条 `[data-dockkit-strip]` 与面板体同属这一层。皮肤只改表现，不改结构。
- 面板表面使用皮肤画布，左边界换成 1px 暖色发丝线，替换宿主自带的冷白线；页签条下方同样一条发丝线，标题行与内容因此分成两层。
- 页签按 Claude Code 面板标题的形态显示：当前页签用主文字色，其余用三级文字色，指针停留时使用皮肤的悬停底色，不画分段控件的底板。
- 面板自带的图标按钮（`data-dockkit-split-button`、`data-sidebar-right-mode`、`data-sidebar-right-toggle`）统一为 28px 方形、6px 圆角、次级文字色。
- 空面板的引导页取皮肤的抬升卡片与暖色发丝线，罗盘图标改用皮肤的文字色阶。
- 空面板的引导页上再加一套皮肤自有的卡片栈：数字读宿主的 `sessionStats` 与 `tokenUsage` 投影，文案用宿主的 `chat` 词条，版面用皮肤的卡片配方；数据缺席时不显示卡片。
- 所有规则限定在 `[data-rightbar-col]` 内：同一批 dockkit 标记也驱动底部面板与浮层面板，那些表面保持宿主自己的样式。
- 颜色规则带配色门控；宽度拖拽、折叠、全屏、页签切换与页签菜单继续由宿主管理。

## 理由

- 宿主的面板表面自带冷白发丝线，与侧栏的暖色表面并排时像另一套界面。
- 面板头部在只有一个页签时就是面板标题，参考截图里的右侧面板也是这样一行。

## 代价

- dockkit 的标记是宿主的内部契约，宿主改版时需要核对。
- 面板体由各个面板插件自己排版，皮肤只改宿主外壳与引导页。

## 重审条件

- 宿主为面板表面与页签提供自己的 `data-*` 标记或令牌时，直接读宿主的标记。
