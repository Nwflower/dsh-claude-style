# D14. 账号表面：一套行模型，两个挂载点

- **状态**：已实施
- **分组**：功能
- **关联**：D16

## 决定

- 插件的行（账号头部、其他插件的页脚条目、设置行）只出现在账号弹层里，由 `features/account/surface.ts` 每轮判定挂载点。
- 宿主有账号区时（桌面端），宿主的账号行就是入口（插件只打标记供样式重绘），插件把容器插到宿主账号菜单列表的首位，宿主渲染它自己的行；宿主没有账号区时（网页端），插件自建账号行与弹层。
- 宿主的行不复制、不移动、不转发点击。插件的行被点击后需要收起菜单时，派发一次带 `__dshHostMenuEscape` 标记的 Escape 交给宿主菜单；皮肤的全局键盘路径见到这个标记就跳过。
- 账号头部打开封号彩蛋时，全窗浮层让指针「离开」行与菜单：浮层打开期间悬停收起停止工作，退出后页脚保持进入时的样子。
- 插进去的容器比宿主自己的行晚一帧到，卡片随之变高，宿主再晚一帧按新高度重新摆位。所以悬停或按下账号行时先给 `<body>` 打 `ACCOUNT_ARMED_ATTR`，卡片在这段时间不上色；`surface.ts` 看到插件的行已在列表里、且卡片的行内摆位连续两次读数相同之后才打 `ACCOUNT_READY_ATTR`，入场动画挂在这个标记上。行内没有摆位时行一到就放行；始终不静止的卡片在有限帧数后放行。

## 理由

- 宿主菜单自带定位、动画、键盘遍历与关闭；插进去的行加入同一套键盘遍历，账号区不依赖宿主菜单的渲染时序与标签文字。
- 淡入从卡片最终的高度与位置开始，不会先贴着底部出现再往上跳。

## 代价

- 宿主菜单关闭即卸载，容器每轮重新确认并插入；卡片的显现要等插件的行到位与宿主重新摆位（约两三帧），这段时间卡片不上色。

## 重审条件

- 宿主为账号菜单提供追加行的插槽时改用插槽；宿主把插件的行算进它自己的首次渲染时，去掉这段等待。
