# D35. 选区样式的作用范围

- **状态**：已实施
- **分组**：运行时

## 决定

- `::selection` 的两条底色规则与内联代码片的四条反相规则只作用于对话正文（`[data-chat-flow]`）与草稿编辑器（`[data-lexical-editor]`）里的块级元素（`p`、`li`、`td`、`th`、`blockquote`、`pre`、`h1`–`h6`）；其余区域（侧栏、设置页、弹层等）的选区交还宿主自己的样式。
- 滚动条保持原样：`*` 上的 `scrollbar-width` / `scrollbar-color` 与全局四条 `::-webkit-scrollbar` 规则（8px 圆角拇指、悬停变色）。

## 理由

- 切换会话与新建会话的卡顿来自一处全文档的 `::selection`：Blink 在每次样式重算里为每个元素计算选区样式。实测一次「切到另一会话再切回」的样式重算合计：全文档作用域 1.6–2.7 s，收窄到正文块级元素 0.3–0.8 s，不装皮肤约 0.05 s；单次切换从 0.9–2.4 s 降到 0.11–0.51 s。
- 选区样式会继承，写在块级元素上的规则覆盖它的行内后代，正文里的选区外观不变。
- 滚动条那四条规则做过同样的对照测量（切换重算、滚动帧距各三组），没有可测差异。

## 代价

- 侧栏、设置页与弹层里的选区回到宿主默认的半透明洗色；以后需要自定义选区的区域，要加进这几条规则的作用范围。

## 重审条件

- 宿主提供选区颜色的公开主题接口时改用宿主的；或 Blink 不再为每个元素计算全文档 `::selection` 时放开作用范围。
