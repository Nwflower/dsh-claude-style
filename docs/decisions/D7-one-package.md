# D7. 行为层与皮肤对外是一个插件

- **状态**：已实施
- **分组**：分发与流程
- **关联**：D29、D30、D46

## 决定

- 模型选择器、权限分段、账号弹层等行为层与皮肤层共享宿主定位点、刷新机制与弹层部件，对外发布为同一个插件；仓库内部怎样分包（D46）不影响这一条。
- 「只要行为、不要外观」的入口是设置页的「配色」与「字体」：两项都选「跟随宿主」后，皮肤不再改写宿主的颜色与字体，只留布局与控件（D30）。
- 每个接管宿主界面的功能另有自己的开关（D29）。

## 理由

- 行为层与皮肤依赖同一套宿主定位与部件，拆成两个插件只会多出一层跨插件协调。

## 代价

- 行为层随皮肤的布局一起安装，不能脱离这个插件单独使用。

## 重审条件

- 出现第二个真实使用者（另一个主题插件或宿主官方）需要复用行为层时，把它拆成独立插件。
