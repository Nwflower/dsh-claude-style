# D30. 配色与字体可以交给宿主

- **状态**：已实施
- **分组**：宿主边界
- **关联**：D7、D16、D50、D51

## 决定

- 「配色」与「字体」两项偏好各有 `claude`（默认）与 `host` 两档，写成 `<body data-dsh-claude-palette>` 与 `<body data-dsh-claude-typeface>`。
- 每条写宿主令牌的规则都挂在 Claude 一档上：写 `--dsw-` 颜色令牌的规则挂配色门，写 `--dsw-font-*` 的规则挂字体门，漏挂即构建失败。把皮肤的画布刷到宿主框架上的规则（`<html>`、`<body>`、`#root`、侧栏、对话列）同样挂在 Claude 一档上。
- 皮肤自己的节点只读私有令牌（`--dsh-claude-*`）与宿主令牌。宿主一档把每个私有令牌改成宿主令牌的别名（对照表在 `docs/STYLE.md` 的「Two palettes」），Claude 一档定义的每个私有令牌在宿主一档都必须有别名。
- 卡片类的面（弹层、账号弹层、搜索面板）用宿主的浮层令牌 `--dsw-alias-bg-overlay`，宿主一档下给共用弹层外壳加背景模糊（D16）。皮肤自造的字体令牌是私有的 `--dsh-claude-font-serif` / `-prose` / `-code` / `-brand`，宿主一档回落到宿主的 `--dsw-font-family` 与 `--ds-font-family-code`。
- 推理强度滑杆顶档的紫色、封号彩蛋页复刻的 Claude 页面在两档下都保留原色；半透明的中性悬停色与用量面板的数据配色写成字面值。

## 理由

- 「跟随宿主」时皮肤不和宿主或其他主题插件（例如 dsh-wallpaper-engine 把画布清空、把浮层改成玻璃）争同一组令牌，结果不取决于样式表的加载先后；皮肤自己的面读别名，跟着别人画的颜色走。

## 代价

- Claude 一档的令牌规则多一个属性选择器；新的私有颜色令牌在 `packages/client/src/theme/tokens.json` 里要同时写 Claude 的值与宿主一档的别名（D51）；功能样式表里画面的颜色要读令牌，不能写字面值。

## 重审条件

- 宿主提供主题层级或令牌分层机制（多个主题插件按层叠加）时改用宿主的。
