# D50. Claude Desktop 侧栏布局

- **状态**：已实施
- **关联**：D19、D22、D43

## 决定

- 按照 Claude Desktop 的顶端工具行、全宽分段控制、导航、工作区会话列表、底部账户行排列。
- 折叠按钮沿用宿主；搜索作为常驻图标，macOS 使用 `_topStrip`，浏览器使用 `_logoRow`。展开侧栏隐藏品牌文字，品牌选择仍控制账户与收起栏标记。
- DSH 的进行中 / 已归档视图使用顶部全宽分段控制，继续调用已有归档列表。标签准确描述 DSH 的功能；工作区标题保持显示。
- 会话行高 32px，字号 14px，空闲状态使用空心圆；选中行使用独立中性灰背景，悬停使用较浅背景。导航图标静止，行高 32px。
- Claude 深色侧栏使用 `#111110`，选中背景 `#343433`，普通会话文字 `#C2C0B8`。这些令牌只在侧栏内覆盖，遵守颜色偏好开关；浅色与跟随宿主保留对应令牌。
- 布局由主题插件覆盖实现，宿主的侧栏宽度、拖拽、键盘导航、会话操作和账户菜单继续由原有控制器管理。

## 理由

- 截图的视觉层次来自常驻工具、明确分区、正常亮度的会话文字和独立选中背景。
- DSH 提供自己的会话和面板功能，主题使用这些功能的名称与控制器，保持标签与实际操作一致。

## 重审条件

- 宿主开放侧栏布局与工具栏插槽后，迁移结构选择器。
