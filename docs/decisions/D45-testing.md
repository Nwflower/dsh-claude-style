# D45. 三层测试与持续集成

- **状态**：待实施
- **关联**：D40、D44、D46、D47
- **现状**：`npm run smoke` 在无界面 Chrome 里对替代宿主页面跑浏览器用例，并对宿主半边跑路由用例；`probe` / `probe-timing` / `shoot` 需要手动启动 `dsh web` 并带上令牌运行；没有持续集成

## 决定

- 单元测试（Vitest）覆盖纯逻辑：弹簧曲线、气泡形状采样、折行分段、吉祥物状态机、偏好解析、观察总线的分发顺序（D40）。毫秒级，改一行就能跑。
- 契约测试见 D44。
- 端到端测试（Playwright）：
  - 启动真实的 `dsh web`，模型服务换成可编排流式节奏的模拟服务（以 `dsh-chat-import/.github/scripts/dsh-mock-llm.mjs` 为起点：它已同时支持 Messages API 与 OpenAI 兼容流，目前只回固定的一句）。
  - 断言两类东西：亮暗两套主题的截图回归；逐帧轨迹——记录每帧画出的滚动位置与动画元素的状态，断言「不倒退、不瞬移」、动画按预期交接。
  - 截图沿用写盘前的隐私替换与泄漏扫描。
- 全部在持续集成上自动运行。
- `.debug/` 里有价值的探针（`race.cjs` 逐帧滚动写入记录、`send-trace.cjs` 发送过程录制、`sample-flight.cjs` 替身采样）升级为有维护的工具：D46 之前放在根目录 `tools/`，之后并入 `packages/testing`。其余草稿在每次会话的任务结束时删除。

## 理由

- 当前的冒烟测试发现得了结构与标记的回归，发现不了真实宿主的时序问题；能发现的工具又需要手动操作，不在日常流程里。

## 代价

- 持续集成要能安装 DSH 与 Chrome，端到端测试耗时以分钟计；截图基线随视觉改动更新。

## 重审条件

- 宿主提供官方的插件测试环境时改用宿主的。
