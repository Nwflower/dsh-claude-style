# D45. 三层测试与持续集成

- **状态**：已实施
- **关联**：D40、D44、D46、D47

## 决定

- 单元测试（Vitest，浏览器模式跑在本机 Chrome 上）覆盖纯逻辑：弹簧曲线、气泡形状采样、折行分段、吉祥物状态机、偏好解析、观察总线的分发顺序（D40）、滚动主人的仲裁与接管（D41）。毫秒级，改一行就能跑。
- 契约测试见 D44：宿主选择器与入口逐条对着真实页面核对。
- 端到端测试（Playwright）跑在装配好的宿主上：
  - `tools/dsh-web.cjs` 起一个临时实例：`$DSH_HOME` 在 `.debug/` 下，本仓库以链接装进它的 web 配置，启动后交出带令牌的地址；通道自己的补丁走 `--patch` 覆盖层，profile 的用户层留给宿主；`resetState` 清掉会话与侧栏缓存，断言页面的场景因此从空会话列表开始。
  - `tools/mock-llm.cjs` 是脚本化的模型服务，按 Messages 协议回答宿主路由，脚本按请求顺序交付；只有模型是脚本化的，agent 循环、会话、客户端各层与渲染都是发行版宿主。
  - `tools/e2e.cjs` 的每个场景各起一套实例，断言各自的东西：`conversation` 读者的消息成行、脚本回答的 Markdown 与思考过程归组；`tool` 工具调用单独成行并带调用编号、结果之后的回答渲染出来；`send` 发送起飞期间替身离开页面、真行不可见、读者的字每一帧都看得见、替身带走了输入卡片的字体；`scroll` 逐帧记录滚动位置与内容高度，断言没有一帧在内容没有变短时倒退、没有一帧在内容没有增长时把尾部留在视野之外；`shots` 亮暗两套截图。
  - 截图沿用写盘前的隐私替换与泄漏扫描（`scripts/privacy.cjs`，与 `scripts/shoot.cjs` 共用），基线在 `tests/screenshots/`，比对按不同像素的比例判定，`--accept` 在看过新图之后刷新基线。
- 持续集成（`.github/workflows/ci.yml`）：构建检查、单元测试与完整冒烟在 Linux 上跑；端到端的行为场景在 Linux 上跑；截图比对在 Windows 上跑，基线就是在那一边拍的。
- `.debug/` 里有价值的探针已升级为有维护的工具：逐帧滚动记录并入 `tools/e2e.cjs` 的 `scroll` 场景，发送过程录制并入 `send` 场景的逐帧采样，替身采样并入同一份采样；其余草稿在会话结束时删除。

## 理由

- 冒烟跑在替代宿主页面上，发现得了结构与标记的回归，发现不了真实宿主的时序问题；只靠人工运行的探针又把这类问题留给了下一次手工排查。

## 代价

- 持续集成要装 DSH、pnpm 与 Chrome，端到端部分耗时以分钟计；截图基线随视觉改动刷新。

## 重审条件

- 宿主提供官方的插件测试环境时改用宿主的。
