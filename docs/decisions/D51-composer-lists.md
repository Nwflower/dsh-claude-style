# D51. 输入框 Markdown 列表编辑

- **状态**：已实施
- **关联**：D4、D19、D43

## 决定

- 列表保存为 Markdown 纯文本：`- `、`* `、`+ `、`• ` 项目符号，以及 `1. `、`1) ` 编号。
- 列表行内 Enter 或 Shift+Enter 续写同样缩进与标记，编号递增；空列表项回车删除标记，退出列表。Ctrl/Cmd+Enter 继续使用宿主发送行为。
- Ctrl/Cmd+Shift+7 切换当前行为编号列表，Ctrl/Cmd+Shift+8 切换当前行为项目符号列表。
- 插入使用当前会话输入器的 `actions.captureInsertion()` 和 `actions.insertText()`，在宿主的草稿修订检查与撤销记录中完成。仅处理绑定到该输入器的可编辑表面；输入法组字与命令候选菜单遵守宿主行为。
- 功能跟随输入区重绘范围；重绘关闭时按键直接交还宿主，插件卸载时释放事件监听。
- 插入服务抛错时遵循功能隔离：报告一次并退役列表编辑，交还宿主按键处理。

## 理由

- 宿主使用纯文本 Lexical 编辑器，其草稿、引用片段、保存和提交都来自自己的文本投影。使用现有插入接口可以维持这些行为一致。

## 重审条件

- 宿主增加原生列表编辑或公开编辑器扩展接口时迁移到原生能力。
