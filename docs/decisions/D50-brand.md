# D50. 品牌两档：配色切换只靠令牌

- **状态**：已实施
- **关联**：D24、D30、D51

## 决定

- 品牌偏好有两档：Claude（默认）与 DeepSeek（值为 `deepseek`；早先存下的 `off` 读作 DeepSeek，`anthropic` 读作 Claude）。
- DeepSeek 一档保留宿主自己的品牌区并画成 DeepSeek 蓝；配色为 Claude 时亮暗两套都换成蓝色系。
- 皮肤自己画的 Claude 标（账号行的兜底头像、轮次状态行的火花）在 DeepSeek 一档换成宿主的鲸鱼标（`FISH_LOGO_PATH`）。
- 配色切换只靠令牌：DeepSeek 的亮暗两块（多一个品牌属性，优先级更高）整组重写宿主的别名令牌与皮肤的私有令牌，各功能样式表一律读令牌。

## 理由

- 品牌只换色板与标志，功能的行为不变；令牌集中重写，功能样式表不必知道当前是哪个品牌。

## 代价

- 新的私有颜色令牌要同时写进 DeepSeek 的亮暗两块。

## 重审条件

- 新品牌带来行为分歧（不同的 DOM 覆盖、不同的输入框结构）时，品牌不再只是一组令牌，改为独立的主题包。
