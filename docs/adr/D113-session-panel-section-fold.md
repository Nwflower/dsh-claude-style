# D113. 会话总览并入宿主会话面板并补齐节折叠，输入区统计栏独立配置

- **取代**：D112、D110、D106、D102、D94

## 背景

宿主加入了会话面板 `@deepseek-ai/dsh-client-ui-session-panel`，作为对话视图右侧的面板，自行负责停靠与浮层形态、开关按钮、停靠偏好、进出动画与节的拖动排序。面板由若干节组成，每节是槽位 `conversation.session.panel.section` 里的一项；环境一节的行是槽位 `conversation.session.panel.environment.row` 的列表；节标题右侧是按节 `id` 分发的 `conversation.session.panel.section.actions`；行的悬停卡片与列表折叠各有一个工厂槽位；所有行共用一套标记属性（`data-session-panel-row` 与 `data-row-part`）。

宿主当前尚未为面板的节提供原生开合能力，但节 DOM 保持固定骨架：`<section data-session-panel-section="<id>">` 下正好两个子元素，首子元素为包含直接子元素 `h2` 的标题行，次子元素为包含 `[data-slot]` 的正文容器。与此同时，上下文弹层与会话面板在对话期间始终承载完整的会话统计与 Token 用量，输入区统计栏需要独立表达自身的显隐与排布，避免与会话面板耦合。

## 决定

- 会话总览进入宿主的会话面板。皮肤不自建独立详情列、不自绘头部详情按钮；停靠、浮层、开关、偏好、进出动画与节的拖动排序都由宿主面板负责。
- 皮肤向 `conversation.session.panel.section` 注册四节，`id` 以 `claude-style-` 开头，`order` 位于环境（0）与变更请求（100）之间：上下文（10）、会话统计（20）、Token 用量（30）、产出（40）。环境一节的工作目录与版本库信息由宿主及 forge 包承担；皮肤向 `conversation.session.panel.environment.row` 注册本机（排在 `project` 之前）与预设（`order` 50，悬停卡片显示预设说明）两行。
- 行使用宿主的行标记（`data-session-panel-row` 与 `data-row-part`），样式表只为上下文占用条与图例、压缩控件、数字表与占位条补充规则；悬停完整信息走 `conversation.session.panel.details`，产出折叠走 `conversation.session.panel.fold`。
- 面板停靠时画成一叠卡片，每节各自带底色、圆角与细线边框；浮层保留宿主的整张卡片；两种状态都隐藏滚动条但保持可滚动。空节渲染为空交由宿主隐藏；上下文、会话统计与 Token 用量在路由回答前用同高占位条站位，产出仅在有文件时出现。宿主面板显示时，会话头部的预设标签及后台工作入口让位给面板对应内容。
- 皮肤监听 `[data-session-panel]` 并对每节 `[data-session-panel-section]` 执行契约探测（`<section>` 元素、无原生折叠属性、二子元素骨架、首子元素含直接 `h2` 且无额外折叠按钮、次子元素含 `[data-slot]`）。探测通过时，为面板全部节启用折叠交互：标题行补齐按钮语义与键盘触发，`h2::after` 绘制折叠箭头，自定义属性控制正文显隐；「会话统计」与「Token 用量」默认收起，其余节默认展开，选择持久化在浏览器本地存储中。
- 皮肤向 `conversation.session.panel.section.actions` 注册四节的收起态摘要数值，仅在对应节收起且折叠增强生效时展示；面板内任意一节未通过契约探测时，立即撤回全部折叠标记与交互并令摘要组件渲染为空，整块面板退回宿主原生形态。
- 上下文弹层与会话面板始终展示完整统计数据。`statsPosition` 只控制输入区统计栏本身，取值为关闭（`off`）、随宽度同行（`footer`）与独立成行（`inline`）：开启时两种排布共享水平位置、六项会话指标与宽度自适应详略阶梯；上下文占用图示在输入区重绘覆盖对话页期间固定在工具栏右侧；Token 单位独立控制统计栏、上下文弹层与会话面板三处数值写法。

## 后果

- 面板的位置、宽度与开合跟随宿主，同时具备分节折叠与收起态摘要，宿主升级引入原生折叠或调整骨架时自动回退而不产生双重折叠。
- 宿主节 `id` 一旦发布保持不变，避免用户排好的顺序失效。
- 输入区统计栏的显隐与会话面板完全解耦，切换统计栏开关或排布模式时工具栏右侧上下文图示保持原位。
- 放弃的做法：保留自绘详情列；在节组件内部自行渲染折叠壳（无法折叠宿主自带节且会产生双标题）；把输入区统计栏关闭态伪装成上下文位置或随会话面板展开隐藏统计栏。

## 重审条件

- 宿主会话面板原生提供节折叠与折叠态回调时，删除皮肤的 DOM 折叠增强与契约探测，改为接入宿主原生接口。
- 宿主把会话统计与用量作为已推送的会话投影交给页面时，改为读取宿主投影，删掉私有路由里的计时与计价汇总。
