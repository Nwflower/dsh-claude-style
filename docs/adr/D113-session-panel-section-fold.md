# D113. 宿主会话面板的节由皮肤补齐折叠，探测到契约变更时自动回退

## 背景

D112 将会话总览并入宿主会话面板 `@deepseek-ai/dsh-client-ui-session-panel`。宿主当前没有为面板的节提供开合能力，皮肤注册的上下文、会话统计、Token 用量与产出各节连同宿主自带的节全部常驻展开，面板在长会话里拉得很长。

宿主面板的节 DOM 目前保持固定结构：`<section data-session-panel-section="<id>">` 下正好两个子元素，首个子元素为包含直接子元素 `h2` 的标题行，第二个子元素为包含 `[data-slot]` 的正文容器；标题行内同时开放了按节 `id` 分发的 `conversation.session.panel.section.actions` 槽位。按 D43，在宿主提供原生节折叠之前，皮肤可以依赖这份契约在浏览器层补齐折叠与收起态摘要读数，并在宿主升级改变该契约或引入原生折叠时立刻退让。

## 决定

- 皮肤监听 `[data-session-panel]` 并对每节 `[data-session-panel-section]` 执行契约探测：确认节元素为 `<section>`、自身不含原生折叠状态属性、正好有两个子元素、首子元素含直接子元素 `h2` 且在 `section.actions` 之外不含原生按钮或折叠控件、次子元素含 `[data-slot]`。
- 探测通过时，皮肤为面板全部节（宿主自带节与皮肤注册节一并）启用折叠交互：在标题行设置按钮语义与键盘触发，通过 `h2::after` 绘制折叠箭头而不向宿主 React 树插入额外 DOM 节点，使用自定义属性控制正文显隐以保持宿主空节判定不受影响；「会话统计」与「Token 用量」默认收起，其余节默认展开，读者手动切换的结果持久化在浏览器本地存储中。
- 皮肤向 `conversation.session.panel.section.actions` 注册上下文、会话统计、Token 用量与产出四节的摘要读数，仅在对应节收起且折叠增强处于生效状态时展示；标题行悬停触发宿主拖拽手柄时跟随宿主原有规则让位。
- 面板内任意一节未能通过契约探测（包括宿主引入原生折叠控件或调整节 DOM 骨架）时，皮肤立即撤回全部节的折叠标记与标题行属性、停止响应折叠交互，并令四节摘要读数组件渲染为空，整块面板退回宿主原生形态。

## 后果

- 面板重新具备分节折叠与收起态摘要读数，同时不干扰宿主原有的拖拽排序与空节隐藏规则。
- 折叠能力依赖宿主节的二子元素骨架与 `data-session-panel-section` 属性；宿主升级引入原生折叠或重构骨架时，皮肤自动回退而不产生双重折叠或布局错乱。
- 放弃的做法：在节组件内部自行渲染折叠壳（无法折叠宿主自带的环境与工作类各节，且会与宿主渲染的 `h2` 标题叠出双标题）。

## 重审条件

- 宿主会话面板原生提供节折叠与折叠态回调时，删除皮肤的 DOM 折叠增强与契约探测，改为接入宿主原生接口。
