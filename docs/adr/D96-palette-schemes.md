# D96. 品牌与配色方案：预设可编辑，读者可自建多套

- **取代**：D30、D50、D64

## 背景

皮肤画的是宿主自己的界面，颜色与字体既可能来自宿主，也可能来自另一个主题插件。品牌要在保留宿主品牌与换成皮肤自带品牌之间切换，而读者还想换上自己的标志，并按自己的喜好调整配色：改动内置色板的某一个颜色，保存几套不同场合的配色，在明暗两种外观下分别指定背景、行内代码与链接的颜色。

这些都只换画出来的样子，不改功能的行为；把它们写成功能里的分支，每张样式表都要知道当前是哪个品牌、哪套配色。品牌与色板若一一绑定，每加一套色板就要加一档品牌，读者的调整也没有地方存放。

## 决定

- 配色与字体各是一项偏好，可以选择跟随宿主；跟随宿主时，皮肤的画面读宿主令牌的别名，结果不取决于样式表的加载先后。
- 品牌按档切换，档决定标志与默认配色方案，不改功能行为；品牌偏好每加一档，功能样式表不动。
- 配色切换只靠令牌：一个方案整套重写宿主别名与皮肤私有令牌，功能样式表一律读令牌。
- 品牌与配色方案是两个集合。每个品牌指向一个默认方案；方案不绑定品牌，任一方案可以在任一品牌下选用。选择「跟随品牌」时，页面画当前品牌的默认方案。
- 方案分内置预设与读者自建两类。预设写在令牌表里，构建时解析为静态色值；自建方案存为偏好。
- 一个方案由四组种子与一个结构属性组成：强调色是单值；背景、行内代码色各是明暗一对；链接色同样是明暗一对，不给时由强调色推出；结构属性是暗色描边的画法（提亮的轮廓或承载面的台阶），它属于方案，同一套颜色在不同品牌下画法一致。侧栏与读者气泡由背景推出；预设可另给手调的侧栏色与气泡色，只在该预设的背景没有被读者改动时保留。
- 一个方案的完整色板由这些种子与一张共用的音阶表推出。音阶表是每个颜色令牌相对种子的明度台阶、彩度与透明度，跨方案共用。
- 预设可以编辑：读者改动的字段记为该预设的覆盖记录，只含改动过的字段。有覆盖记录的预设按读者自建方案的方式在页面里由相对颜色算出，没有覆盖记录的预设保持构建时的静态值；删除覆盖记录即恢复默认。预设不能重命名或删除。
- 读者可以新建、复制、重命名与删除自建方案，数量有上限；删除正在使用的方案时，选择回到「跟随品牌」。「跟随品牌」改变的是选用哪套方案，「恢复默认」清除的是某个预设的改动，两者各自独立。
- 方案存成一个字符串列表偏好，每项是一条 JSON 记录；预设的覆盖记录与自建方案放在同一个列表里，以 id 区分。选用的方案另存一个 id，取值为「跟随品牌」或某个方案的 id。两个半边读同一份记录的解析与校验；一条记录解析失败时只丢弃这一条，并报告错误（D12）。选用的 id 找不到对应方案时，页面画「跟随品牌」并报告错误。
- 每个预设都要满足对比度：行内代码色与链接色对背景至少 4.5:1，强调色对背景至少 3:1，明暗两套都要满足；不满足时构建失败。读者编辑时只显示当前对比度读数，不阻止保存。
- 标志的着色不属于配色方案：它跟随「标志颜色」这一项偏好，取值是标志原色（按品牌）、强调色与文字色三种；设置页的品牌区预览按它画出品牌标志与读者上传的图片。
- 自定义品牌是叠在所选品牌之上的一层：名称、标志图、文字标志与标志着色方式各自独立，读者没提供的那一项保持所选品牌原样。
- 自定义品牌不带来行为分歧；某一项带来行为分歧时，它按独立主题包处理，不并入这一层。
- 皮肤自己定义的颜色令牌，每个预设都要有对应的取值或别名，漏掉即构建失败。
- 音阶推不出的颜色保持字面值：推理滑块的 apex 紫、焦点环、涟漪波前、峰谷计费与投影。
- 强调色与方案只在皮肤自带的配色下生效；选择跟随宿主时整个方案列表都不出现，读者存下的取值留着。
- 早先版本存下的值读入后按新形态解释：单一强调色与四个自定义颜色成为一套名为「自定义」的自建方案并被选中，画面与存值时一样；行内代码色选项「经典暖色」成为 Claude 预设的覆盖记录。

## 后果

- 新加一个预设只写一组种子，品牌与功能样式表都不动；改一处共用音阶，所有预设一起走。
- 色板与标志分开：品牌标志的墨色按品牌属性写在色板块之外，选用另一个方案时标志不跟着换。
- 共用音阶表让每个预设的多数颜色落在手挑值附近而不是原值上，个别强调与墨色最多差几个 ΔE00；方案与方案之间不再各自手调。
- 构建输出解析后的静态色值，未被改动的预设在页面里没有颜色公式；取色、对比度检查与外观快照读到的都是最终颜色。
- 读者自建方案与有覆盖记录的预设例外：它们的令牌是相对颜色表达式，页面里算出最终颜色，读自定义属性拿到的是表达式本身；强调色上的文字色按强调色与明暗背景在写入时算好。
- 强调色的悬停色，以及未给链接色时的链接色，仍按固定比例混出，个别颜色上不如手调的调色板准。
- 方案记录使用字符串列表是因为宿主的设置表单只接受字符串、布尔值与字符串数组（D73）；记录的字段变化要在两个半边共用的解析里一并处理。
- 皮肤自带的私有令牌每加一条，都要在跟随宿主的一档里补上别名，并进音阶表。
- 功能样式表里画面的颜色一律读令牌；写死颜色在跟随宿主时会被别人画的颜色盖住。
- 自定义标志图由宿主半边收下并存进读者自己的目录，升级插件而宿主未重启时这些图缺席。
- 放弃的做法：为每个品牌写一套按品牌分支的规则；把自定义品牌做成再添一档品牌；让每个预设各带一张音阶表；让品牌与色板一一绑定；预设只读、另设一张自定义卡供读者复制修改；在偏好里用对象类型存方案。

## 重审条件

- 宿主提供主题层级或令牌分层机制时，配色与字体改用宿主的层级。
- 宿主提供插件级的文件存储服务时，自定义标志图改存到那里。
- 宿主的设置表单接受对象类型的偏好时，方案记录改存为结构化值。
- 宿主侧栏的品牌标志与名称插槽成为稳定扩展点时，侧栏的标志与名称改为注册插槽组件。
- 新品牌带来行为分歧时，品牌不再只是一组令牌，改为独立的主题包。
- 某个预设需要音阶表表达不出的颜色时，先给它加一条音阶或一个结构属性；同一种颜色在预设与预设之间反复手调，说明音阶表该重新分档。
