# D94. 会话总览是对话右侧的详情栏，数据由宿主半边折叠

## 背景

读者看一次会话时，周边信息散在几处：工作目录与仓库在会话头部，上下文占用在头部的读数里，产出、变更与后台任务各自在别的入口。Claude Code Desktop 把这类信息收在对话右侧的一列「对话详情」里，窗口够宽时它自己出现，窄时自动退避，不是右栏里与其它页签并列的一页。

宿主这一代没有为这类列留扩展点：右栏的容器被 `dsh-client-ui-sidebar-right` 占用，其页签类型要求以页签身份注册，与截图里的独立详情栏语义不同；根级浮层槽位只提供一块挂在页面上的区域，列的位置与宽度要自己算。D43 允许在扩展点不足处用 DOM 与样式补齐，因此详情栏由皮肤自绘，数据仍走宿主半边的私有路由。

## 决定

- 详情栏是皮肤自己的列：安装时在页面上挂一个容器并渲染 React 根，列用 `position: fixed` 贴住对话列的右边缘，宽度固定 300px。它不占用宿主右栏的页签，也不出现在 guide 卡片里；会话头部的工具栏保留一个按钮，用于收起这一栏或在窄窗口里手动打开它。
- 列随对话列的宽度自动开合：窗口宽 ≥ 1360px 且对话列宽 ≥ 860px 时展开，窗口 < 1180px 或对话列 < 760px 时退避，两条阈值留出迟滞；读者手动收起后，本次会话不再自动打开，换会话恢复自动；头部按钮与栏自己的关闭控件做同一个选择。
- 展开时挤压对话宽度而不是浮在对话上：样式按页面标记给中心列加右侧内边距，标题、转录与输入框一起变窄；收起后标记摘掉，布局复原。
- 栏内按节读取当前会话：环境（本机、工作目录、仓库与分支）、上下文占用与分项、会话统计、产出、变更、后台任务。产出、变更与后台任务没有内容时整节省略，每个列表显示两条、其余折叠，顺序一律最新在前（产出、变更、进程、子智能体）；每个列表不再设条数上限，展开可看到会话里的全部行；后台任务按进程、子智能体与团队分组，各组只在有行时出现、各自折叠。
- 会话统计取宿主半边的计时与用量投影：回合与步骤数、模型用时、工具调用用时、首 token 平均、输出速度、缓存命中、费用，以及未缓存输入、缓存读取、缓存写入与输出的 token 分项。费用沿用宿主的结算结果与读者自己的价目行，页面把行带进请求，宿主按同一张表计价。
- 预设文本进栏：头部预设按钮保留，栏顶重复显示同一段文本，随宿主切换预设更新。
- 轮询只在栏挂着时发生：一次只允许一个请求在飞，新的请求作废旧的，避免较早的回答盖掉较新的状态；与上一次相同的回答不进入渲染；页面不可见时不取数。
- 读数按会话隔离：答案记在回答它的会话名下，切换会话后不显示上一会话的环境、产出与任务；新会话首次请求失败时显示失败，不保留旧答案。作废的请求不能再清理控制器或安排下一次轮询，只有当前请求可以。
- 会话统计的费用跟随读者的计费币种：结算结果同时带人民币与美元，栏按设置选择并沿用既有货币格式；计费关闭时不显示费用行。
- 面板安装后标题栏里宿主的子智能体与后台任务入口不再承担信息：栏展开时用样式隐藏这两个入口，它们的行由 Background tasks 一节承接；团队与预设入口保持原位。栏退避或收起后入口复原，窄窗口不丢这两类信息。

## 后果

- 详情栏与宿主右栏互不影响：宿主右栏开着时中心列变窄，详情栏按阈值可能自动退避；读者也可以关掉右栏让详情栏回来。
- 挤压对话会重排转录与标题行：开合发生在宽度跨越阈值这一刻，迟滞避免窗口边缘的抖动；转录的重排在长会话里有一次成本，与窗口缩放相同。
- 宿主在流式输出期间重建列节点时，栏只按自身观察到的宽度与结构变化重算位置，不跟随宿主节点身份；这一层用页面标记与列盒子的测量，不读宿主右栏的内部状态。
- 详情栏的数据落后一个轮询周期；会话统计随结算推进，流式中的估算不进入栏内。
- 宿主若提供独立的详情列扩展点，改为在该槽位注册并删掉自绘列的定位与挤压样式。
- 宿主若不提供会话计时投影或价目表，统计节只显示它拿得到的项；缺项不报错，也不留空行。

## 重审条件

- 宿主为右侧详情列提供官方槽位或宽度策略时，改用宿主的，删掉自绘的定位、阈值与挤压规则。
- 宿主把会话统计与用量作为已推送的会话投影交给页面时，改为读投影，删掉路由里的计时与计价折叠。
- 读者对自动开合的阈值或手动收起的持久范围有不同预期时，阈值与抑制规则集中在一处，按反馈调整。
