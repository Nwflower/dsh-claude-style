# D94. 会话总览是对话右侧的详情栏，数据由宿主半边折叠

## 背景

读者看一次会话时，周边信息散在几处：工作目录与仓库在会话头部，上下文占用在头部的读数里，产出、变更与后台任务各自在别的入口。Claude Code Desktop 把这类信息收在对话右侧的一列「对话详情」里，窗口够宽时它自己出现，窄时自动退避，不是右栏里与其它页签并列的一页。

宿主这一代没有为这类列留扩展点：右栏的容器被 `dsh-client-ui-sidebar-right` 占用，其页签类型要求以页签身份注册，与截图里的独立详情栏语义不同；根级浮层槽位只提供一块挂在页面上的区域，列的位置与宽度要自己算。D43 允许在扩展点不足处用 DOM 与样式补齐，因此详情栏由皮肤自绘，数据仍走宿主半边的私有路由。

## 决定

- 详情栏是皮肤自己的列：安装时在页面上挂一个容器并渲染 React 根，列用 `position: fixed` 贴住对话列的右边缘，宽度固定 320px，与对话主体让出的宽度相同。它不占用宿主右栏的页签，也不出现在 guide 卡片里；会话头部的工具栏保留一个按钮，用于收起这一栏或在窄窗口里手动打开它。
- 列随对话列的宽度自动开合：窗口宽 ≥ 1360px 且对话列宽 ≥ 860px 时展开，窗口 < 1180px 或对话列 < 760px 时退避，两条阈值留出迟滞。读者通过会话头部按钮手动收起后，这个选择记在浏览器里，所有会话与重启之后都保持收起，直到再按一次按钮；按开会清掉这个选择，当前会话不论宽度都保持展开，之后的会话重新按宽度自动开合。自动开合没有单独的设置项：不想被打扰的读者按一次就够，其余读者的行为不变。
- 宿主右栏优先占这一侧：宿主右栏自身有宽度时不展开，手动打开也退让；读者关掉右栏后按原选择恢复，读者在右栏打开时按会话头部的详情按钮，先把右栏收起，宽度回来后再交给自己。
- 宿主在对话下缘浮起的底部面板（`dsh-better-sidebar` 的那一面）横跨整列宽度，比详情栏占的宽度更宽：它站着时详情栏的下缘停在它的上缘，两者都完整可读；面板收起后详情栏收回对话列的底边。栏的顶边是对话头部的下缘，两处读数合起来就是栏的盒子。
- 展开时挤压对话宽度而不是浮在对话上：样式按页面标记给会话头部之下那块主体盒子加右侧外边距，转录与输入框变窄，会话头部保持整列的宽度，标题与工具栏因此落在栏的上方；栏的上沿取会话头部的下沿，栏与头部各占自己的一段高度。收起后标记摘掉，布局复原。
- 两条边是一条边：栏的宽度从对话的右边缘长出来或收回去，主体盒的外边距同时长同时收，两者取同一段时长与同一条曲线，宿主的列动画也是这一段。栏读的是「这一侧归谁」这件事本身——外框在列开始移动的那一帧就写下归谁，栏据此进出，不等右栏宽度走到零。栏的位置在尺寸回调里直接写到元素上，交接期间随对话列一帧一帧地走。
- 栏属于读者正在看的那段对话：宿主处于会话相位、对话在主列里可见、转写里已有一行，三者齐备栏才站着。从一段站着栏的对话切换到另一段对话时，宿主在切换开始的那一帧写下新会话的 id，过几帧才挂出它的行；这几帧里页面标记、栏的宽度与主体盒的外边距都保持原样，栏内的读数换成新会话的。切换到首页、对话被隐藏、或同一会话的转写失去全部的行时，栏照常退场。
- 栏是一块裁切：栏的盒子按宽度收放，栏内的正文始终贴着右边缘不动，宽度变化只揭开或盖住它，于是读者看到的始终是对话的边与栏的边这两条。退场时先摘掉页面标记（对话立即开始回宽、头部入口复原、数据不再取），再把宽度过渡回零，过渡结束才卸载节点；中途再打开会把这个过渡掉头，不从头播放。读者选了「减少动效」时两条过渡都不发生，位置一步到位。
- 栏内按节读取当前会话：环境（本机、工作目录；工作目录在仓库里时再加仓库名与分支）、上下文占用与分项、会话统计、Token 用量、产出、变更、进程、任务、子智能体与团队。工作目录本身不是仓库时环境只列本机与目录，目录下的其它仓库不进入这一节。各类工作独立成节，有内容时才出现，直接使用节标题；产出与变更显示两条，其余折叠。工作节展示所有运行项，已结束项合为一行计数，展开后可以读取全部记录，顺序保持最新在前。
- 栏的首帧不等整份答案：上下文一节的占用、窗口与占比取自宿主的占用投影帧，标题与正文先就位，分项位置留一行正在读取的说明，宿主折叠返回后由各部分接手；环境、产出、变更与工作各节随那份回答一起出现。整栏不会停在单独一句正在读取。
- 进程涵盖整个会话的命令工具调用，包含前台等待、主动后台与超时转后台；前后台归属由创建调用和宿主工具结果证明，只有作业注册记录时保持未知。命令调用与它注册的作业合为一条记录；没有注册作业的前台命令也保留历史与输出，停止控制器只接收真实作业身份。非命令作业进入任务一节。
- 产出一节只显示最新用户轮次的内容。真实用户追加消息开始新轮，工具结果、后台通知、目标继续与自动续行均不切轮；新轮开始即清空旧产出，本轮尚无产出时省略该节。进程、任务、子智能体、团队看板与变更绑定维持会话级范围：子智能体一节列出本会话开始过的每一个子智能体，运行中的排在前，已结束的折成计数，标题栏那个入口在栏展开时让位之后，它的全部记录都在这一节里读到。
- 运行中的进程与可继续子智能体各带独立的停止按钮，与展开输出或打开子会话的按钮并列。第一次点击显示确认，再次点击才请求宿主停止；失去焦点取消确认，请求中禁用，宿主接受后显示正在停止，实际结束由宿主状态确认。失败在该行显示并可重试。进程沿用宿主任务控制器及用户取消原因，子智能体沿用宿主的父子关系授权中断，均不以模型身份请求取消；一次性或未知模式的子智能体保留原有会话入口。
- 每一节用原生折叠控件独立开合。环境、上下文、产出、变更与后台任务初次挂载时展开；会话统计与 Token 用量是两张数字表，初次挂载时收起，各留一个读者最常看的数字在标题右侧。标题旁的箭头跟随开合，收起时右侧保留工作目录名、上下文占比与小色条、输出速度、费用或条目数；会话还没有输出速度时显示回合数，没有费用时显示 token 总量。数据刷新保留读者的开合选择，节内的列表展开与已打开的任务输出随内容一起保留。
- 整栏只用一种正文字号与一种行距，层级靠字重与墨色区分，字重只留给节标题；每一行只占一行，标题在前、细节在后，行尾的状态是带状态色的文字。全栏的密度由此固定，新增的行与节沿用同一套行式。
- 收起的节只占标题那一行，读数留在标题右侧；分隔线画在节的上沿，每一节都画自己那条，不看邻居的开合。标题行不铺悬停底板：它是栏里的分界，不是列表的行。展开的节静止时不显示箭头，指针移上标题或键盘聚焦时才出现，收起的节一直显示。
- 栏内内容超出时整栏自己滚动，不画滚动条：栏只有 320px，右边缘那 10px 若站一条滚动条，会读成对话与详情栏之间第二条边线。
- 工作节的标题使用常规字重，已结束记录折叠成计数。进程行用命令终端图标，名称在前，前后台归属与耗时独立位于行尾，停止按钮与名称同一行；子智能体沿用同样的行式。已结束行不重复写结束状态，失败用错误色，需要读出退出码时打开该行的输出。
- 两张数字表取宿主半边的计时与用量投影。会话统计回答这次会话怎么跑的：回合与步骤数、输出速度、首 token 平均、模型用时、工具调用用时。Token 用量回答这次会话花了多少：费用、缓存命中，以及未缓存输入、缓存读取、缓存写入与输出的 token 分项。费用沿用宿主的结算结果与读者自己的价目行，页面把行带进请求，宿主按同一张表计价。
- 「对话统计信息位置」有一档「跟随详情栏」：栏展开时输入区下方那行统计不绘制，数字由栏里的两张表承接；栏退避或收起时那一行照「独立成行」显示。那一行隐藏时保留自己的盒子，输入区的高度不随栏的开合变化。其余三档与栏互不影响，想两处都看的读者不受这一档约束。
- 上下文分项是估算值，占用总量是服务商的读数：分项数字不带估算记号，图例下方用一行小字说明，提示里写明校准方式。分项的价格从哪里来、按什么拆分，见 D99。
- 产出一节的行写文件名与所在目录；绝大多数产出都是写入的，所以只有模型主动展示的文件带状态字。行首的图标是单色线形的纸页，图片换成相框，全栏的彩色只留在上下文图例上。
- 统计的每个数值按宿主自己的写法印出：时长取宿主读数的紧凑写法（不足一分钟带一位小数），token 计数用宿主的分组分隔符与它自己的单位模板，速度、缓存命中同样走宿主那几条格式规则；底部那行读数与这一节是同一个会话的两个面，措辞一致。
- 预设文本进栏：环境一节的最后一行显示预设名，行上的提示是预设自己的说明，随宿主切换预设更新。头部的预设标签只是一段带提示的文字，栏展开时由这一行承接、标签让位，栏退避或收起后标签复原。栏从环境标题开始。
- 轮询只在栏挂着时发生：一次只允许一个请求在飞，新的请求作废旧的，避免较早的回答盖掉较新的状态；与上一次相同的回答不进入渲染；页面不可见时不取数。宿主落下一帧统计就唤醒一次，并按最短间隔合并，这一次越过宿主保留的答案，环境、上下文、产出、变更与后台任务因此更快一步跟上。两张数字表不走这条路由：宿主按步结算，路由里的数是上一次结算，它们读的是底部那行读数所用的同一份实时读数。
- 读数按会话隔离：答案记在回答它的会话名下，切换会话后不显示上一会话的环境、产出与任务；新会话首次请求失败时显示失败，不保留旧答案。作废的请求不能再清理控制器或安排下一次轮询，只有当前请求可以。
- 会话统计的费用跟随读者的计费币种：结算结果同时带人民币与美元，栏按设置选择并沿用既有货币格式；计费关闭时不显示费用行。
- 面板安装后标题栏里宿主的子智能体与后台任务入口不再承担信息：栏展开时用样式隐藏这两个入口，它们的行由进程、任务与子智能体各节承接；团队入口能打开宿主自己的面板，保持原位。栏退避或收起后入口复原，窄窗口不丢这两类信息。

## 后果

- 详情栏与宿主右栏共用右侧：宿主右栏占住宽度时详情栏退让，读者关掉它之后按原选择恢复；读者在右栏打开时按详情按钮，收起的顺序是右栏先，详情栏后。
- 挤压对话会重排转录与输入框：一次开合在 300ms 里每帧重排一次，成本与宿主自己开合侧栏相同；窗口缩放的抖动由阈值迟滞避免。会话头部不随开合变宽变窄，它的工具栏与页签在开合前后停在原处。
- 退场的 300ms 里栏仍在文档上，读者点不到它，页面标记已经摘掉，读数取到最后一帧为止。
- 宿主在流式输出期间重建列节点时，栏只按自身观察到的宽度与结构变化重算位置，不跟随宿主节点身份；这一层用页面标记与两列盒子的测量，不读宿主右栏内部的页签与状态。
- 两张数字表读统计功能发布的那一份实时读数，与底部读数同源同刻：宿主按步结算的投影数加上流式回答的估算，栏里的 token 与费用因此在一整段回答里连续前进，而不是等这一步结算时跳一次。这份读数按底部那行读数的同一条时长与曲线逐帧推向新值，数字增长的方式与那行一致；读者选了「减少动效」时两处都直接写新值。环境、上下文、产出、变更与后台任务仍落后一个轮询周期。
- 宿主若提供独立的详情列扩展点，改为在该槽位注册并删掉自绘列的定位与挤压样式。
- 宿主若不提供会话计时投影或价目表，统计节只显示它拿得到的项；缺项不报错，也不留空行。

## 重审条件

- 宿主为右侧详情列提供官方槽位或宽度策略时，改用宿主的，删掉自绘的定位、阈值与挤压规则。
- 宿主把会话统计与用量作为已推送的会话投影交给页面时，改为读投影，删掉路由里的计时与计价折叠。
- 读者对自动开合的阈值或手动收起的持久范围有不同预期时，阈值与抑制规则集中在一处，按反馈调整。
