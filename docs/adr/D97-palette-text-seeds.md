# D97. 配色方案增加正文种子

- **取代**：D96、D30、D50、D64

## 背景

配色方案已经能够保存强调色、背景、行内代码与链接色。深色外观的正文仍只由背景明度推出，读者无法单独降低正文亮度。正文种子需要进入同一套方案记录与音阶，默认色板的既有颜色保持不变。

## 决定

- 配色与字体各是一项偏好，可以选择跟随宿主；跟随宿主时读取宿主令牌别名。品牌决定标志与默认方案，方案可以独立选择。
- 方案数量有上限，记录长度、名称长度与标识长度由共享解析器限制。预设不能重命名或删除，自建方案可以。
- 方案分内置预设与读者自建两类。预设写在令牌表中并解析为静态色值；自建方案与预设覆盖记录存为字符串列表偏好，一条记录只含读者设置过的种子。
- 一个方案包含强调色、背景、正文、行内代码、链接与暗色描边结构。背景、正文、行内代码与链接色各有明暗一对；未设置的字段继承方案的基础预设。
- 正文是独立种子。正文音阶以它为零点，次级文字、说明文字与扫光使用相对明度、彩度与透明度。内置预设显式记录既有正文色，因此新增种子的默认输出与原有色板一致。
- 侧栏与读者气泡由背景推出；预设可以保留手调值，背景未被覆盖时这些手调值继续生效。
- 方案可以选择、复制、重命名与删除；预设可以编辑并恢复默认。选择跟随品牌与清除某个预设的覆盖记录是两项独立操作。
- 配色切换只通过令牌完成，功能样式表不读取品牌或方案条件。自定义方案由品牌层写入种子，生成样式表用相对颜色计算完整色板。
- 每个预设的正文、行内代码与链接色对背景至少达到 4.5:1，强调色对背景至少达到 3:1；构建检查这些对比度。编辑器显示当前读数，读者可以保存自己的选择。
- 标志着色独立于方案，可以选择品牌原色、强调色或正文色。自定义品牌只改变名称、标志与文字标志，不引入行为分歧。
- 旧版单一强调色与自定义背景记录迁移为一套自建方案。无法解析的单条记录被丢弃并报告，其它记录继续读取。

## 后果

- 读者可以单独调暗深色正文，同时保留背景、侧栏与强调色。
- 正文音阶的默认值由显式种子承接，新增字段不改变已有用户的画面。
- 方案记录增加一个向后兼容的可选字段；旧版本读取新记录时会忽略该字段。
- 自定义正文影响所有读取正文音阶的令牌，品牌与功能样式表无需增加分支。
- 放弃的做法：为正文亮度增加一个脱离方案的独立百分比。那样会使正文与背景、方案预设及明暗外观失去同一组记录。

## 重审条件

- 宿主提供主题层级或结构化方案记录时，配色与字体改接宿主机制。
- 宿主设置表单接受对象类型的偏好时，方案记录改存结构化值。
