# D98. 设置文案只写影响范围

## 背景

设置页的说明文字最初写成教程，讲机制、讲窗口行为，一条说明常常占三四行。2026-11-05 统一收成「控制…」的短句，随后新加的行又各按当次手感写回去：字体一行列举三档选项，配色编辑区的附注解释读数的定义，对话详情一行罗列栏内十来个区块。规则此前只写在一次重构方案里，仓库没有决定页，工具也不作判定，每加一行设置就要重新判断一次，同类说明因此有几种写法并存。

## 决定

- 设置行的说明只写影响范围：改动这一项之后，读者在界面上看到什么不同。
- 说明不复述本行标题，不解释选项名词，不写实现方式，不写开关两种状态各自的样子。
- 中英文说同一件事，句式不要求逐字对应。
- 没有影响范围可写的行留空说明，不用一句话充数。
- 说明显示在标题下方；附注显示在说明下方，按强调色画出，只用于需要读者动手的情况。附注写缺什么、去哪里补、何时生效，一句交代完，不展开原理。
- 读数不算说明：百分比、对比度、项数这类量允许带单位与阈值，越过阈值时由样式标出。
- 说明重复本行标题、出现 `ERROR` 或版本号形态、中英键集合不一致都有客观判据，评审按这三条核对；是否在解释选项名词由评审判断。

## 后果

- 说明变短，读者读到的只有一次判断。
- 纯装饰或纯读数的行没有范围可写，说明留空，标题与控件自己承担表意。
- 新加设置行时先回答「关掉它，界面哪里不一样」，答不上来的行要么不带说明，要么这一项本不该出现。
- 已有的说明里按实现方式写、以动词开头的条目，按本页逐条改写；本轮改的是这一轮新加的三条。

## 重审条件

- 某一项的效果一句话说不清时，先拆成两行或两个开关，而不是把说明写长。
- 设置页出现必须读完一段话才能判断的选项时（例如两个开关的组合效果），说明可以例外地写成一段，代价与用法写在该行旁边。
