# D112. 会话总览是宿主会话面板里的几节，输入区统计栏独立配置

- **取代**：D110、D106、D102、D94

## 背景

宿主 0.2.3-alpha.2 加入了会话面板 `@deepseek-ai/dsh-client-ui-session-panel`。它是对话视图右侧的一块面板：宿主自己决定停靠与浮层形态、开关按钮、停靠偏好与进出动画。面板由若干节组成，每节是槽位 `conversation.session.panel.section` 里的一项；环境一节的行是槽位 `conversation.session.panel.environment.row` 的列表；节标题右侧是按节 `id` 分发的 `conversation.session.panel.section.actions`；行的悬停卡片与列表折叠各有一个工厂槽位；所有行共用一套标记属性（`data-session-panel-row` 与 `data-row-part`）。宿主自己注册了环境、变更请求、子智能体、共享任务与后台任务五节。

与此同时，上下文弹层与宿主会话面板里的两张统计表在对话期间始终承载完整的会话统计与 Token 用量。此前的 `statsPosition` 仍保留「收进上下文」与「跟随会话面板」两档，前者实际只是隐藏输入区统计栏，后者只在面板展开时把独立行文字隐去并留下空行盒子；同时水平位置与指标勾选仅对「紧凑底栏」开放，「独立成行」无法复用同一套指标和停靠规则，设置页在未选「紧凑底栏」时呈现大段置灰子项与重复附注。

## 决定

- 会话总览进入宿主的会话面板。皮肤不再挂自己的列、不再画会话头部的详情按钮，停靠、浮层、开关、偏好、进出动画与节的拖动排序都由宿主面板负责。
- 皮肤向 `conversation.session.panel.section` 注册四节，`id` 以 `claude-style-` 开头，`order` 位于环境（0）与变更请求（100）之间：上下文（10）、会话统计（20）、Token 用量（30）、产出（40）。节标题取自皮肤自己的文案，展开状态下标题右侧不重复正文已有读数。
- 环境一节的工作目录与版本库信息交给宿主及 forge 包承担，宿主半边路由只回答会话的工作目录供产出定位与打开文件。皮肤向 `conversation.session.panel.environment.row` 注册本机（排在 `project` 之前）与预设（`order` 50，提示显示预设说明）两行。工作类信息交给宿主自己的节，前台命令调用历史留在转写中。
- 行使用宿主的行标记（`data-session-panel-row` 与 `data-row-part`），样式表只为上下文占用条与图例、压缩控件、数字表与占位条补充规则；悬停完整信息走 `conversation.session.panel.details`，产出折叠走 `conversation.session.panel.fold`。
- 面板停靠时画成一叠卡片，每节各自带底色、圆角与同色同宽细线；浮层保留宿主的整张卡片；两种状态都不画滚动条但保持可滚动，浮层右内边距恢复为 8px；节标题保持面板界面字体。
- 空节渲染为空交由宿主隐藏；上下文、会话统计与 Token 用量在路由回答前用同高占位条站位，产出仅在有文件时出现。同一会话的各节共享一份按会话轮询的来源，两张数字表与输入区统计栏读取统计功能发布的同一份实时读数。
- 宿主面板显示时，页面保留标记使会话头部的预设标签、宿主子智能体与后台任务入口让位给面板对应内容；宿主没有会话面板槽位时页面不出现总览。
- 上下文弹层与会话面板始终展示完整统计数据。`statsPosition` 只管输入区统计栏本身，取值收敛为关闭（`off`）、随宽度同行（`footer`）与独立成行（`inline`）：开启时两种排布方式共享水平停靠方向、六项会话级聚合指标与同一套宽度自适应详略阶梯；上下文占用图示在输入区重绘覆盖对话页期间始终固定在工具栏右侧；Token 单位独立控制统计栏、上下文弹层与会话面板三处读数；设置页通过标题行总开关按需展开双排布实时预览卡片、水平位置与多选指标胶囊。

## 后果

- 面板的位置、宽度与开合完全跟随宿主；宿主节 `id` 一旦发布保持不变，避免读者排好的顺序失效；面板自行无滚动条滚动。
- 输入区统计栏的关闭状态不再伪装成上下文位置，会话面板展开也不再隐去输入区统计栏或留下空白底栏行；切换统计栏开关或切换同行与换行模式时，工具栏右侧的上下文圆环与饼图保持原位不动。
- 放弃的做法：保留自绘详情列或把整份总览塞进单一节（与宿主面板冲突且重复环境行）；在 `statsPosition` 中保留「收进上下文」与「跟随会话面板」档位或为两种排布维护两套指标与测量规则（造成名不副实的选项与成片置灰子项）。

## 重审条件

- 宿主为面板的节提供开合能力时，两张数字表改回初次挂载时收起，收起的节在标题右侧重新给出读数。
- 宿主把会话统计与用量作为已推送的会话投影交给页面时，改为读投影，删掉路由里的计时与计价折叠。
