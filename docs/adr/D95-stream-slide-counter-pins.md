# D95. 流式输出的跟随由宿主写位置，皮肤只画位移并抵消吸附元素的跳动

- **取代**：D85、D71

## 背景

流式输出时，宿主的跟随在内容每次长高时把滚动位置一步写到末尾，读者看到上方文字一帧跳上去。皮肤早先在同一帧里把宿主写下的末尾拉回去，再用弹簧逐帧把位置滑过去；那样每一帧都有一次位置写入与布局读取，输出越密主线程越忙。

改用画面上的合成器位移之后，还有两处细节需要同时成立：一是真实提供方分片到达的间隔往往短于滑动令牌的时长，替换式位移动画重启时若固定采用完整令牌时长，未走完的距离会持续累加；二是消息列里的吸附定位元素——固定在底部的等待行，以及长思考展开后吸附在滚动视口顶部的思考标题行——它们的吸附位置已经在布局阶段按末尾算定，消息列施加向下的合成器位移时会把它们一并往下推，造成每一片内容到达时顶部思考标题向下跳动并反复触发指针悬停闪烁。

## 决定

- 流式输出期间皮肤不写滚动位置。宿主的跟随照常在内容长高时把位置写到末尾，皮肤保留宿主写入的结果。
- 平滑效果由画面上的合成器位移给出：内容长高的那一帧，宿主写完末尾之后、画面绘制之前，皮肤把消息列向下推回本帧实际产生的正向滚动位移，再让这段位移回到零。位移交给合成器完成，不触发布局，也不产生滚动事件。
- 同一时刻只运行一段替换式位移动画；新的增长到来时，从上一段尚未走完的剩余距离接着算起，替换正在运行的那一段。
- 每一段滑动的时长取相邻两片增长的间隔，最长不超过滑动时长的令牌。间隔短于令牌时，一段滑动在下一次增长到达时恰好走完，带下去的距离收敛在单次增长之内；间隔长于令牌时按令牌时长停稳。
- 消息列内处于吸附状态的元素同步施加方向相反、时长与曲线相同的合成器位移：底部等待行与顶部已进入吸附状态的展开思考标题各自抵消消息列的向下位移，在画面上保持静止；思考行结束或移出时立即终止正在运行的位移。
- 仅在宿主标明正在跟随末尾、读者没有离开末尾、折叠过渡不在进行时才启动位移；读者一有上滑或接管意图，正在进行的位移立即停止。
- 读者持有阅读位置期间，宿主若仍在增长时把位置写到末尾，皮肤在同一帧把读者的位置写回（滚动来源 reader，D40）。写回使宿主进入采样窗口并关闭自身的跟随，此后不再改写阅读位置。
- 结构时刻把读者交还给宿主跟随、皮肤自身的跳转与折叠过渡仍经由滚动主人仲裁（D40）。

## 后果

- 流式输出的布局开销维持在宿主原生跟随的水平，宿主的跟随在整个输出过程中保持开启。
- 读者落后于末尾的位移距离收敛在单次增长的量级上，最新一行始终处于可视区附近。
- 底部等待行与顶部吸顶的展开思考标题在整个流式输出期间保持原位，消除顶部标题跳动以及静止指针下的悬停态与光标形态闪烁。
- 读者持有期间每次增长有一次位置写入与一次布局，直至宿主的采样窗口结算完毕并停止改写末尾。
- 位移运行期间普通流内元素的屏幕位置与布局位置相差当前位移量；读者的滚动意图会先终止位移，再进入位置读取（D84）。
- 放弃的做法：把每一段滑动固定为令牌全长；让连续增长叠加多段动画；忽略顶部吸附标题而只抵消底部等待行。

## 重审条件

- 宿主自身的跟随提供平滑过渡，或开放可替换的跟随策略时，本处的合成器位移退场。
- 宿主改变消息列或展开思考标题的包裹与吸附结构，使消息列的位移改变滚动容器高度或标题不再相对滚动视口吸附时，重新核实抵消对象与范围。
