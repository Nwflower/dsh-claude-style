# D71. 流式输出的跟随由宿主写位置，皮肤只画位移

## 背景

流式输出时，宿主的跟随在内容每次长高时把滚动位置一步写到末尾，读者看到上方文字一帧跳上去。皮肤原先在同一帧里把宿主写下的末尾拉回去，再用弹簧逐帧把位置滑过去。这样每一帧都有一次位置写入：宿主的滚动处理跟着读一次位置，每帧都要重新布局，多个会话同时输出时尤其明显；位置停在离末尾一段距离的地方，宿主把它当成读者离开了末尾，关掉自己的跟随，皮肤又要藏起它的回到底部按钮、再设法把跟随找回来。平滑的代价大半花在和宿主互相抵消上，输出越密，主线程越忙，滑动反而越慢。

## 决定

- 流式输出期间皮肤不写滚动位置。宿主的跟随照常在内容长高时把位置写到末尾，皮肤不拉回、不接管。
- 平滑由画面上的位移给出：内容长高的那一帧，宿主写完末尾之后、画面绘制之前，皮肤把消息列向下推回长高的距离，再让这段位移回到零。位移交给合成器完成，不触发布局，也不产生滚动事件。
- 同一时刻只有一段位移动画；新的增长到来时，从仍未走完的那段距离接着算起，替换正在运行的那一段。叠加式的动画不能交给合成器，所以不用。
- 钉在底部的元素（等待行）随消息列一起被推开，因此给它同步一段方向相反、时刻相同的位移，两者相抵，它在画面上不动。
- 只在宿主自己标明正在跟随末尾、读者没有离开末尾、折叠动画不在进行时才推；读者一有滚动意图，正在进行的位移立即停下。
- 读者持有位置期间宿主仍在每次长高时把位置钉到末尾，这一段增长在同一帧写回读者的位置（滚动来源 reader，D40）。写回本身让宿主进入它自己的采样窗口，宿主的跟随随即关掉，此后不再钉；读者只是按住屏幕而没有移动时，这是他唯一能停下来的路径。
- 结构时刻把读者交还给宿主跟随、皮肤自己的跳转与折叠过渡仍经滚动主人（D40）。

## 后果

- 流式输出的开销回到宿主自己跟随时的水平；宿主的跟随在整个输出过程中保持开启，皮肤不再需要藏起它的按钮或在输出期间把它找回来。
- 读者持有期间每次增长有一次位置写入与一次布局，代价是让位置按得住；这段长度由宿主的采样窗口决定，窗口一开它就不再钉。
- 新内容在画面上落后于末尾的距离不超过一段位移动画能走完的范围，比逐帧弹簧追赶时更短。
- 位移期间元素的屏幕位置与布局位置相差这段位移：按屏幕位置读取的代码（宿主的当前轮次判定、皮肤的轮次导航）在这段时间里读到的位置有偏差。宿主只在读者离开末尾之后才读这些位置，而读者的意图会先让位移停下。
- 消息列里其他吸附定位的元素（展开行的吸顶标题）没有反向位移，被吸住时会随位移短暂移动。

## 重审条件

- 宿主自己的跟随提供平滑的写法，或开放可替换的跟随策略时，这里的位移退场。
- 宿主改变消息列的包裹结构，使消息列的位移溢出到滚动容器、改变它的可滚动高度时，这套做法要重新核实。
